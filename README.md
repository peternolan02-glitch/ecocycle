# EcoCycle — SDG 12: Responsible Consumption & Production

**Module:** Object Oriented Programming (NCI Year 2)  
**UN SDG:** Goal 12 — Responsible Consumption and Production

## Team Members

- **Section A (Waste & Recycling Tracker):** Jamie Stackpoole
- **Section B (Carbon Footprint Logger):** Valentin Gabriel Luchian
- **Section C (Reuse Marketplace):** Peter Nolan

## Project Structure

- **`ecocycle`**: Main app launcher (`EcoCycleApp`) and shared interfaces (`ImpactCalculable`, `Tradable`).
- **`recycling`**: Household waste logging and recycling guidance.
- **`footprint`**: Transport and energy carbon footprint logger.
- **`marketplace`**: Swap and donation noticeboard for unwanted items.

## How to Run

1. Open the project folder in your IDE (VS Code or NetBeans).
2. Ensure Java is installed and configured.
3. Run `EcoCycleApp.java` from the `ecocycle` package to open the Main Menu.
